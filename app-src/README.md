# VAYNORA app (Expo / React Native)

Stage 1: Today (morning message, task, 5 prayers, habits, night report), chain + XP + ranks + badges + certificate, Fajr alarm + sleep plan, reminders (prayers, sport, night shield, own tasks), emergency button (10-minute rule + relapse protocol), shop (planner, cash on delivery via Instagram DM).

- Install: `npm install`
- Run: `npx expo start` (open in Expo Go)
- Web preview: `npx expo export --platform web` (served at /VAYNORA/app/)
- Store builds: `npx eas-cli@latest build -p android`
