# سجل التحديثات — مهارة مجتبى خليفة للمونتاج

## النسخة 2 — بعد تجربتها على فيديوهات حقيقية
- 👋 ترحيب مجتبى خليفة بأول الجلسة.
- ⚙️ كرت إعدادات واحد بأزرار: الجودة · المنصة · الذكاء الاصطناعي · النص المكتوب.
- 🎬 **4K و60 إطار** بكل الخط: القص، الرسم، التجميع، ريموشن. الإحداثيات تبقى 1080×1920 والتكبير تلقائي (حتى الظلال والبلور).
- 🔍 فحص الفيديو: تدوير آيفون (كان يكسر القص) · الإطارات الحقيقية (آيفون يكتب 60 والفيديو 30) · HDR.
- 🎨 هيقزفيلد اختياري: صور · مقاطع بي-رول · مؤثرات صوتية — بخطة وكلفة وموافقة قبل أي توليد.
- 🧩 `12_broll.sh` + `BROLL` / `clipImg` / `img` بالقالب — المقاطع والصور الجاهزة تنرسم بفريمها الصحيح.
- 🔊 `sfx.json` يقبل ملفات صوت جاهزة (`files`).
- ⚡ تفريغ يختار الموديل حسب كرت الشاشة (large-v3 بـ~٢٠ ثانية) + تلميح من النص المكتوب + إعادة تفريغ مقطع وحده.
- ⚡ رسم بالتوازي (عدة رسّامين) + تجميع بكرت الشاشة للـ4K + وقت باقي تقريبي.
- 📱 منطقة آمنة لانستقرام · تيك توك · شورتس — والصور الخلفية ما تنحسب خطأ.
- 📦 نسخة 1080 خفيفة تلقائياً لو الفيديو 4K.
- 🪟 ويندوز بالكامل: كروم/إيدج، بايثون، ترميز العربي، فلتر القص الطويل، و«الكلام ورا الشخص» بموديل مجاني.
